## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.5 要求按里程碑交付与放款；一次性放款风险过高。
- 改动内容：
  - 新增 `src/domain/milestone/service.ts`：`plan()` / `submit()`。
  - 拆分校验：节点 1-5 个、标题 2-60 字、交付物 10-2000 字、比例合计 10000（万分比）。
  - 金额以**中标报价**为基数按比例取整，最后节点承接余数。
  - 一次性拆分：已有节点拒绝重复设置（CONFLICT）。
  - 提交节点时需求 `IN_PROGRESS → ACCEPTING`（仅首次），写状态日志。
  - API：`POST /api/projects/[id]/milestones`、`POST /api/milestones/[id]/submit`。
  - UI：`MilestonePlanForm`（可增删节点、实时显示比例合计）、`MilestoneActions`（提交交付物）。
- 影响范围：项目开工前必须先拆里程碑；需求详情展示项目执行面板。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm test`：111 用例全绿（本功能 6 例）
  - `npm run build`：EXIT=0（最终全量构建 41 条路由全部生成）
