### v0.4 — 2026-11-23 — 合规闸门重构（部署后修复）

- 背景：`MockSmsGateway` / `MockKycGateway` 在 `NODE_ENV=production` 下无条件抛错，导致生产构建的演示实例**根本无法登录**（注册第一步就 500）。而 `assertProductionPaymentSafe()` 只在启动钩子里判一次，规则散落在三处、判分不一致。
- 改动内容：
  - `src/lib/env.ts` 新增统一闸门 `assertMockAdapterAllowed(kind)`：`NODE_ENV=production` 时默认抛「合规红线」；仅当显式 `APP_ENV=demo` 放行，并**每个适配器只告警一次**。`assertProductionPaymentSafe()` 改为复用该闸门。
  - 新增 `APP_ENV` 环境变量（`production` 默认 / `demo`），compose 透传；`deploy.sh` 在部署前拦截「`PAYMENT_ADAPTER=mock` 且非 demo」的组合，避免容器崩溃循环。
  - `src/instrumentation.ts` 的运行时判断由 `!== "nodejs"` 改为 `=== "edge"`：standalone 下 `NEXT_RUNTIME` 可能为空，旧写法会静默跳过合规校验。
  - `createPaymentGateway()` 内再加一道同规则校验（真正动钱前拦截），防止自定义入口绕过启动钩子。
  - 新增 `tests/unit/compliance-gate.test.ts`（4 例）锁死该规则。
- 影响范围：登录/实名在演示实例恢复可用；正式环境仍需接入真实服务商，否则启动即失败。
- 验证方式：`npx vitest run` 129 例全绿；部署环境冒烟脚本三个账号均能收码、登录、实名。

### v0.7 — 2026-11-23 — Bug 修复（明文 HTTP 站点登录不上）

- 背景：用户反馈"登录不上"。排查证据链：① 审计日志显示其 IP `192.168.100.89` 在 1 分钟内反复出现 `LOGIN_SUCCESS (method=password)`；② 抓登录响应头，`set-cookie: cd_session=...; Secure; HttpOnly; SameSite=lax`；③ 演示实例为 `http://192.168.100.91:8000` 明文 HTTP。浏览器会拒绝在非安全上下文保存 `Secure` Cookie，于是接口成功但会话不落地，跳转 `/console` 又被 middleware 弹回 `/login`，表现为"密码正确但登录不上"。
- 根因：Cookie `Secure` 属性直接绑定 `NODE_ENV === "production"`，未考虑实际请求协议；此前冒烟用 curl 验证，掩盖了浏览器侧行为。
- 改动内容：
  - `src/lib/session.ts`：新增 `cookieSecureFor(headers, url, mode)`——按 nginx 透传的 `X-Forwarded-Proto` 判断（https 才加 Secure），缺头时回退请求 URL 协议；`sessionCookie.options(secure)` 保持原签名。
  - `src/lib/env.ts`：新增 `SESSION_COOKIE_SECURE`（`auto|true|false`，默认 `auto`）。
  - 三处签发会话的路由统一改用该函数：`/api/auth/verify`、`/api/auth/register`、`/api/auth/password/login`。
  - `docker-compose.prod.yml`、`deploy/.env.production.example`：透传并说明该变量；nginx 已透传 `X-Forwarded-Proto $scheme`，无需改动。
  - 新增 `tests/unit/session-cookie.test.ts`（6 例）：http/https/多级代理/大小写/缺头回退/强制开关/Cookie 基础属性。
- 影响范围：仅会话 Cookie 属性计算；JWT、middleware、登录业务逻辑不变。**生产 HTTPS 部署仍自动带 Secure，安全不回退**；HTTP 演示站恢复可登录。
- 验证方式：
  - `npx tsc --noEmit` 0 错误；`npx vitest run` 22 文件 213 例全绿。
  - 部署后登录响应 `set-cookie` 不再含 `Secure`；带 Cookie 访问 `/console` 返回 **200**（此前为 302 回登录页），`/api/auth/me` 返回 200。
  - 三套冒烟全部通过。
