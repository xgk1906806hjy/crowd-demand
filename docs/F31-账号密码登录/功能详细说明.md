## 1. 功能目标

在验证码登录（F01）之外提供两条便捷路径：① 已注册用户设置密码后，可用「手机号或邮箱 + 密码」直接登录，不必每次收验证码；② 手机号注册的用户可绑定邮箱，绑定后两种标识指向同一账号。验证码登录仍是注册入口与兜底方式。

## 2. 用户故事

- 作为老用户，我想设置一个密码，以便下次登录不用等短信。
- 作为手机号注册的用户，我想绑定邮箱，以便手机号停用后仍能登录。
- 作为攻击者视角的防御需求：密码不能被暴力尝试，账号存在性不能被枚举，密码明文不能落库。
- 边界场景：
  - 连续输错密码 → 账号临时锁定，提示稍后再试或用验证码登录。
  - 绑定的邮箱已被其他账号占用 → 拒绝并提示。
  - 未设置密码的账号用密码登录 → 统一报「账号或密码错误」，不泄露账号状态。

## 3. 详细需求

### 3.1 输入

| 字段 | 类型 | 必填 | 校验规则 |
| --- | --- | --- | --- |
| password | string | 是 | 固定 8 位；数字开头；必须含大写字母、小写字母、英文特殊符号；仅可打印 ASCII（不含空格/中文）（2026-11-23 变更，原 8–64 位字母+数字） |
| currentPassword | string | 改密时必填 | 与已存密码比对 |
| account | string | 密码登录时必填 | 用户名、手机号或邮箱格式（F32 扩展） |
| email | string | 绑定时必填 | 合法邮箱，≤254 字符，统一小写 |
| code | string | 绑定时必填 | 6 位数字，purpose=BIND 的邮箱验证码 |

### 3.2 输出

- 设置/修改密码：`{ updated: true }`。
- 密码登录：与 F01 verify 相同——`{ token, user }` + HttpOnly Cookie。
- 绑定邮箱：`{ email }`；`/api/auth/me` 增加 `email`、`hasPassword` 字段（绝不返回哈希）。

### 3.3 业务规则

1. 密码用 **scrypt**（N=16384, r=8, p=1, 32 字节）+ 每用户随机 16 字节盐哈希，存储格式 `scrypt$<saltHex>$<hashHex>`；比对用恒定时间比较。禁止明文/可逆存储。
2. 首次设置密码无需旧密码（登录态即凭证）；已有密码时修改必须提供 `currentPassword`。
3. 密码登录账号标识为手机号或邮箱；**账号不存在、未设密码、密码错误一律返回同一文案**「账号或密码错误」，防枚举。
4. 防爆破：同一账号连续失败 5 次锁定 15 分钟（`passwordLockedUntil`）；锁定期拒绝并提示可用验证码登录；成功登录清零计数。
5. 绑定邮箱需邮箱验证码（purpose=BIND，与 LOGIN 码隔离，互不通用）；邮箱全局唯一，已被占用返回 CONFLICT；绑定不改变手机号。
6. 邮箱验证码登录（F01 扩展）：首次登录自动注册（email 唯一）；**不与手机号账号自动合并**——合并必须走登录态下的显式绑定，防止账号接管。
7. 所有事件写审计：PASSWORD_SET / PASSWORD_LOGIN_SUCCESS / PASSWORD_WRONG / PASSWORD_LOCKED / EMAIL_BOUND。

### 3.4 状态流转

密码生命周期：`未设置 → 已设置 → 已修改`；锁定状态：`正常 → 锁定（失败5次）→ 正常（15分钟后或验证码登录成功后不清锁，仅密码成功清计数）`。

### 3.5 权限

| 角色 | 可执行操作 |
| --- | --- |
| 访客 | 密码登录 |
| 已登录用户 | 设置/修改自己的密码、绑定自己的邮箱 |
| 运营方 | 无特殊权限（不提供查看/重置他人密码能力） |

## 5. 验收标准

- [x] 设置密码后可用手机号+密码、邮箱+密码登录
- [x] 改密必须验旧密码；弱密码被拒绝
- [x] 连续失败 5 次锁定 15 分钟，锁定期验证码登录不受影响
- [x] 账号不存在/未设密码/密码错误返回同一文案
- [x] 绑定邮箱后邮箱验证码与密码登录均落到同一账号
- [x] 邮箱被占用时绑定返回 CONFLICT
- [x] BIND 码不能用于登录，LOGIN 码不能用于绑定
- [x] 单元测试通过；真实实例冒烟通过（smoke-auth 30 项）
- [ ] Playwright E2E（待统一补）

## 6. 测试要点

- scrypt 哈希可校验、错误密码拒绝、盐随机（同密码两次哈希不同）。
- 密码强度校验（固定 8 位、数字开头、大小写字母 + 特殊符号、仅可打印 ASCII）。
- 失败计数递增、第 5 次触发锁定、锁定期拒绝、成功清零。
- 防枚举：三种失败分支文案一致。
- 绑定：验证码错误/过期/被占用/成功；BIND 与 LOGIN 码隔离。
- 审计事件在关键节点产生。
