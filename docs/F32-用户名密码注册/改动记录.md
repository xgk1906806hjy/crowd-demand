## 详细记录

### v0.1 — 2026-11-23 — 新建

- 背景：用户要求"先把注册功能实现，先不依赖手机和邮箱验证"。此前注册只有验证码首次登录自动注册一条路径（F01），验证码通道未接真实凭据时外部用户无法注册。PRD 升 v0.4，开发方案登记 F32。
- 改动内容：创建功能档案，确定方案——用户名（4-20 位、字母开头、字母/数字/下划线、小写归一、保留词）+ 密码直接注册并自动登录；密码登录账号扩展为用户名/手机号/邮箱；同 IP 每小时限注册 5 个；资金操作仍强制实名。
- 影响范围：认证入口；F01/F31 既有行为保持不变。
- 验证方式：见后续实现记录。

### v0.2 — 2026-11-23 — 上线

- 背景：按 v0.1 方案实现并部署。
- 改动内容：
  - `prisma/schema.prisma`：`User.username String? @unique` + 索引；`prisma/init.sql` 重生成；增量 `prisma/patches/2026-11-23-f32-username.sql`（幂等，已在服务器执行）。
  - 新增 `src/domain/auth/username.ts`：4-20 位、字母开头、字母/数字/下划线、小写归一、保留词（admin/administrator/root/system/support/official/service/help）。
  - `src/domain/auth/service.ts`：`register()`（查重 + P2002 并发兜底 + 注册即签发会话 + 审计 REGISTER_SUCCESS）；进程内 IP 滑动窗口限流（每 IP 每小时 5 次**成功**注册，失败请求不占额度）；`passwordLogin` 账号三选一；锁定/防枚举文案调整（详见 F31 改动记录 v0.3）。
  - 新增 `POST /api/auth/register`（201 + 会话 Cookie）；`me` 返回 username；登录页新增「注册」Tab（用户名/密码/确认密码）；安全设置展示用户名。
  - 新增 `tests/unit/auth-register.test.ts`（18 例）；`deploy/smoke-auth.sh` 追加 11 项注册断言（30→41 项）。
- 影响范围：认证入口与 User 表；验证码登录、手机号/邮箱密码登录、资金护栏均不变。
