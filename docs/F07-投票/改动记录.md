## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.2 要求登录用户一人一票；开发方案 5.3 明确 MVP 用「实名用户一人一票 + 数据库唯一约束」作为反刷票前置约束。
- 改动内容：
  - 新增 `src/domain/vote/service.ts`：`VoteService.cast()` / `cancel()`。
  - 三重闸门：实名校验、`(needId,userId)` 唯一约束、仅 `COLLECTING` 可投。
  - 事务内完成「写票 → `voteCount` 自增 → 达标条件更新 `COLLECTING→PLEDGING` → 写状态日志」。
  - 新增 API `POST /api/needs/[id]/vote`（`action: UP | CANCEL`）。
  - 新增客户端组件 `VoteButton`：未登录引导登录、未实名引导实名、已投可撤回、票数即时更新。
- 影响范围：
  - 票数冗余字段 `Need.voteCount` 与 `Vote` 表严格同步。
  - 达标后需求进入承诺期，投票关闭。
  - 每次投票/撤票写 `AuditLog`（action=VOTE）。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm test`：70 用例全绿（投票 7 例）
  - `npm run build`：EXIT=0
