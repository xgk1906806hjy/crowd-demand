## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.1 要求需求可被公开浏览并按金额/票数/时间排序，同时给出详情以支撑投票与后续承诺决策。
- 改动内容：
  - 新增 `src/domain/need/query.ts`：`NeedQueryService.list()` / `detail()` / `top()`；金额以「分」字符串输出，避免 bigint 序列化失败。
  - 新增 API：`GET /api/needs`（列表、支持 `scope=mine`）、`GET /api/needs/[id]`（详情）。
  - 新增页面：`src/app/(public)/needs/page.tsx`（排序 Tab、状态筛选、关键词搜索、分页）、`src/app/(public)/needs/[id]/page.tsx`（详情 + 生命周期时间线 + 投票/发起者操作）。
  - 新增组件：`NeedCard`、`StatusBadge`、`Progress`；新增 `src/lib/display.ts`（金额/日期/倒计时格式化）。
  - 根布局接入 `SiteHeader` 全站导航。
- 影响范围：
  - 草稿对列表不可见；他人草稿详情按 404 处理。
  - 数据库不可用时页面降级提示，不白屏。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm test`：70 用例全绿
  - `npm run build`：EXIT=0，`/needs`、`/needs/[id]` 正常生成
