## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.2 要求热度榜（票数）与承诺榜（金额）；开发方案强调「票 ≠ 钱」，两个信号必须分开展示。
- 改动内容：
  - `src/domain/need/query.ts` 新增 `NEED_SORTS`、`SORT_LABEL`、`normalizeSort`、`buildNeedOrderBy`、`computeProgress`、`NeedQueryService.top()`。
  - 四种口径：hot（票数降序）、pledge（承诺金额降序）、latest（发布时间降序）、deadline（截止时间升序），均带 `id asc` 稳定次级排序。
  - 首页 `src/app/page.tsx` 改造为双榜单（各取 3 条）+ 空态 + 数据库不可用降级。
  - 需求广场顶部新增排序 Tab。
- 影响范围：
  - 榜单只读 `Need` 冗余字段，不做聚合查询；`pledgedAmount` 由 F09 维护。
  - 非法 `sort` 静默回退热度榜，不阻断浏览。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm test`：70 用例全绿（排序 9 例）
  - `npm run build`：EXIT=0
