## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.8 要求运营方可查看资金流水与托管状态，支撑对账。
- 改动内容：
  - 新增 `src/domain/ledger/query.ts`：`overview()` 返回托管余额、累计承诺/放款/退款与最近流水。
  - 余额复用 `balanceOf`（ΣCREDIT − ΣDEBIT），不引入余额字段。
  - API `GET /api/admin/ledger`（仅 OPERATOR）。
  - 页面 `/admin/ledger`：四张汇总卡 + 流水表格（时间/账户/方向/金额/余额快照/业务/备注）。
- 影响范围：只读；不提供修改入口。
- 已知限制：MVP 全量读取流水计算余额，数据量大后改余额表 + 快照。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm run build`：EXIT=0（最终全量构建 41 条路由全部生成）
