  - 接口层：`src/app/api/kyc/{submit,status}/route.ts`。
  - 表现层：`src/app/(console)/console/kyc/page.tsx`；控制台加入口。
- 影响范围：为 F04/F09/F12 提供实名前置换门；不改动既有 F01 逻辑。
- 验证方式：
  - `npm run typecheck`：0 错误。
  - `npm test`：新增 `id-number.test.ts`（6 例）、`kyc-service.test.ts`（7 例），全量 34 例通过。
  - `npm run build`：EXIT=0，16 个页面全部生成；新增 `/api/kyc/submit`、`/api/kyc/status` 与 `/console/kyc` 均正常编译。
- 合规核对：身份证号仅存 HMAC 哈希、无明文；一人一号唯一约束；KYC 事件写审计；生产环境禁用 mock 适配器。
