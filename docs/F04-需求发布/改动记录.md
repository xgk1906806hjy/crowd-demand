## 详细记录

### v0.1 — 2026-11-21 — 新建

- 背景：PRD 5.1 要求任何实名用户能发布需求，且描述质量直接影响后续开发者能否报价。M2 阶段 B 以此为入口。
- 改动内容：
  - 新增 `src/domain/need/service.ts`：`NeedService.create()`，校验标题 5-60 字、描述 30-5000 字、目标金额 100-1,000,000 元、截止时间未来且 ≤365 天、附件 ≤9 个、票数门槛 1-10000。
  - 新增 `src/app/api/needs/route.ts` POST：会话鉴权、`yuanToCents` 金额转换、deadline 解析，统一 `toResponse` 映射错误码。
  - 新增页面 `src/app/(console)/console/needs/new/page.tsx`：发布表单、即时字数提示、合规文案。
  - `prisma/schema.prisma`：`Need` 增加 `voteCount`、`pledgedAmount` 冗余字段及复合索引（服务 F07/F08）。
- 影响范围：
  - 新发布需求默认 `COLLECTING`；`publish=false` 时存为 `DRAFT`。
  - 首次发布自动追加 `REQUESTER` 角色。
  - 未实名用户（`kycStatus != VERIFIED`）返回 `FORBIDDEN`。
- 验证方式：
  - `npm run typecheck`：0 错误
  - `npm test`：10 文件 / 70 用例全绿（F04 相关 7 例）
  - `npm run build`：EXIT=0，21 条路由全部生成
